# Scientific boundary — Vertical Slice V1

The reference run validates only file/container structure. It does **not** establish scientific validity, cosmological equivalence, novelty, patentability, production safety or semantic meaning.

For an RLL scientific claim, promotion requires all factors:

```text
C = D x B x M x F x R
```

- D: versioned data;
- B: explicit baseline;
- M: declared metric;
- F: executable falsifier;
- R: reproducible receipt.

Any absent factor produces `TOKEN_VAZIO`; repetition, symbolic coherence or a green syntax check cannot compensate for missing evidence.
