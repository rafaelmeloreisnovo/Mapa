## 0. Regra-mãe

A sessão não é convertida em teoria única. Ela vira um **campo de hipóteses governado**.

```text
IDEIA -> TOKEN -> RELAÇÃO -> FONTE -> EQUAÇÃO/OBSERVÁVEL -> BASELINE -> FALSIFICADOR -> ESTADO -> NEXT
```

Toda unidade nasce como `TOKEN_VAZIO` quando falta sustentação. `TOKEN_VAZIO` não é zero, erro nem conclusão negativa.

A evolução entre gerações é:

```math
V_{g+1}=VALIDATED(V_g) \oplus \Delta_{g+1}
```

onde o histórico é imutável e contradições são adicionadas como relações explícitas.
