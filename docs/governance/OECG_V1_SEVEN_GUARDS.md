# OECG V1 seven guards

`P C E C U R R` is not a score; it is a completeness/audit panel.

- **Provenance** — source, revision/hash, transformation lineage.
- **Context** — objective, scope, time, environment, authority boundary.
- **Evidence** — exact observable supporting the bounded state.
- **Contradiction** — preserved conflicting observations and discriminators.
- **Uncertainty** — unresolved knowledge/measurement/model/provider/authority/privacy/reproduction dimensions.
- **Reproduction** — pinned inputs/operators/environment and repeated output evidence.
- **Rollback** — reversible/superseding route with preserved history.

A missing applicable guard remains TOKEN_VAZIO and prevents the dependent promotion.
