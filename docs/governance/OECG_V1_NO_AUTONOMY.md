# OECG V1 — no-autonomy boundary

The continuous-improvement loop may change routing, sequencing and reversible implementation details only inside a human-authorized objective.

It must not:

- invent new objectives;
- widen scope because a model/dataset suggests it;
- treat recurrence or semantic similarity as causal authority;
- promote a claim because it is internally coherent;
- bypass privacy, dignity, child-safety, authorship/license or source authority;
- silently turn TOKEN_VAZIO into a default;
- continue mutating after the cycle exit condition is met.

`ADAPTATION != AUTONOMOUS_GOAL_CREATION`

`DATASET_INFORMS_CONTEXT != DATASET_AUTHORIZES_OBJECTIVE`
