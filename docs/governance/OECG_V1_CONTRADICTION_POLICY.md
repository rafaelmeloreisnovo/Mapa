# OECG V1 contradiction policy

A contradiction is a first-class record, not noise to remove for consistency.

When two credible observations conflict:

1. preserve both source/revision references;
2. scope each observation by time/population/environment;
3. mark the disputed state `CONTRADICTED` or `TOKEN_VAZIO` as appropriate;
4. define a discriminating test/probe when possible;
5. append the resolution or supersession; never erase the historical conflict.

A resolved contradiction does not make the earlier receipt false about what was observed at that earlier time.
