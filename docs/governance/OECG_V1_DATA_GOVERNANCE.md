# OECG V1 data governance minimums

For data-bearing work units, bind when applicable:

- data/source owner or authority state;
- collection/source purpose;
- data class and privacy class;
- minimization boundary;
- retention/publication boundary;
- lineage/dedupe identity;
- transformation version;
- access/authorization reference;
- dataset revision/hash;
- derived-vs-raw distinction;
- deletion/retention constraints where authorized and legally applicable.

A governance manifest does not create rights over third-party data and does not itself establish legal compliance.
