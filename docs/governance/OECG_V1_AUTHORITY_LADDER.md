# OECG V1 authority ladder

Authority is typed; no layer inherits another automatically.

1. **Human objective authority** — defines/authorizes the current purpose and bounded scope.
2. **Source authority** — identifies where an observation/document/data item originates.
3. **Producer authority** — repository/system responsible for implementation/runtime state.
4. **Authorship authority** — evidence-backed authority over original authorship/rights for an expression/artifact.
5. **Sense authority** — binds intended meaning in a namespace/context.
6. **Claim authority** — evidence/gates sufficient to promote a bounded claim.
7. **Provider authority** — external platform configuration/state observed from the provider.

`ACCESS != AUTHORITY`

`ACTOR != AUTHORSHIP`

`AUTHORSHIP != SENSE_TRUTH`

`SOURCE != CLAIM`

Any unresolved required rung remains typed TOKEN_VAZIO and blocks only the promotion that depends on it.
