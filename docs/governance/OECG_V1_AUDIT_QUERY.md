# OECG V1 minimum audit query

For any material state, an auditor should be able to ask and recover:

1. What was the human-authorized objective?
2. What source/revision/hash was used?
3. What was changed and by which authority?
4. What test/readback was executed?
5. What contradicted or limited the result?
6. What uncertainty remained?
7. Could the bounded result be reproduced?
8. How can the change be rolled back/superseded?
9. Which Nibiguiri/recovery items remain and why?
10. What exact F_next is authorized, if any?

If the record cannot answer an applicable question, that field is a typed gap rather than an assumed answer.
