# OECG V1 claim-promotion rule

Identity, intention, faith, authorship, internal coherence, file existence and CI status are not substitutes for evidence appropriate to a claim.

A claim can only move to `VERIFIED_LIMITED` when its exact evidence/gates close within an explicit scope and population/window. No OECG V1 artifact grants global claim authority.

`claim_allowed=false` remains the default in this V1 package.
