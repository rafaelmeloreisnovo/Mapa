# OECG V1 provenance policy

A material record should be able to answer:

- what source/object was observed;
- where it was located;
- which revision/hash/time identifies the observation;
- what transformation produced the derived artifact;
- which actor/tool executed the transformation;
- what evidence/receipt resulted;
- what is derived versus original/source-bound.

Unknown provenance fields remain typed gaps. A hash can support identity/integrity of bytes; it does not prove authorship, semantic equivalence or lawful rights by itself.
