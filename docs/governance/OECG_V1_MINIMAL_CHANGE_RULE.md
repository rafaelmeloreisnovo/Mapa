# OECG V1 smallest reversible delta rule

Before a mutation, answer:

- Is it new, duplicate, contradictory or a supersession?
- Which authority owns it?
- Which typed gap does it close?
- What evidence can verify the change?
- What is the rollback/supersession path?

Do not mutate when the change only duplicates existing policy or increases apparent completeness without reducing a demonstrated risk/gap.

This rule applies to OECG successors as well: V1 itself is not exempt from simplification or correction.
