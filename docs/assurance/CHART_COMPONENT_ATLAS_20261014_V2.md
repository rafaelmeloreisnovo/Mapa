## 2. Relation model (do not collapse)

Each `records[]` element has a stable id, kind, source scope, component breakdown, state, upstream/owner, blocking gates, `claim_allowed=false`.  

`OBSERVED_IN` = located in an actual source.  
`HAS_COMPONENT` = child part actually declared/read.  
`HAS_REPRESENTATION` = alternative SVG/DOT/PNG, with no automatic equivalence.  
`DERIVED_FROM` = input transformed into another artifact, requiring producer receipt.  
`DEPICTS` = visualization expresses a model but does not implement it.  
`IMPLEMENTS` = executable verified implementation, requiring source and tests; none inferred from a picture.  
`DUPLICATE_CANDIDATE` = similar filenames/copies not yet compared by content digest.  
`CANDIDATE_ASSOCIATION` = lexical or contextual connection, evidence weight ZERO until independent proof.  
`REQUIRES_GATE` and `PROVENANCE_CORRECTION` preserve why a claim remains held.

Lineage for admissible figures:
`source owner → file ID/path/commit → SHA/source identity → input data and units → transformation/generator → component/series/axis → rendered artifact → test/receipt → claim gate`. Every absent link remains typed `TOKEN_VAZIO`, never 0 or PASS.

## 3. Source control and privacy

The 51 NOVOexport JSON shards were previously byte-read and structurally indexed via *mixed-provider* custody (the original Drive occurrence of ordinal 018 remains different from its Gmail witness). That **does not prove** that every chart described in conversations is materialized as an asset, nor any matching between a Drive global-search result and those shards. There is no raw conversation text, private Drive file ID or user content in this registry.

**Third-party guard:** Office security fixtures must not be opened as active document payloads or reused as original code. Flutter Dart UI components remain upstream. Generic charts and data caches are not independent scientific datasets.

**Freestanding principle:** A future C/ASM L0 parser or geometry verifier must accept bounded caller-owned bytes, no libc/heap/syscalls, deterministic fixed schemas and typed unknowns. This GitHub validator is **hosted Python metadata tooling only**; it does not run in L0 and does not pretend to implement the renderer.
