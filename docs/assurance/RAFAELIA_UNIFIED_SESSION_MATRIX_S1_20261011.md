## 4. Graph schema and navigation

- Nodes: one composite view, 26 vector nodes, 25 typed gap nodes,
  three producer *routes*. Total = **55 nodes**.
- Edges: `HAS_VECTOR`, `ROUTES_TO`, `BLOCKED_BY`.
  Current **99 typed edges**; exact correspondence checked by validator.
- Every edge has a provenance class and epistemic state.
  These are **metadata routes**, not experimentally observed causal links.
- Gap nodes have evidence requests and falsifiers; **absence remains
  navigable and useful**, even where closure is blocked.
- Avoid any reverse inference from `BLOCKED_BY` to `CAUSES`.

## 5. Typed empty ≠ numeric zero

The discriminant registry distinguishes:

`NUMERIC_ZERO`, `RESIDUE_ZERO`, `EMPTY_SET`, `NULL_VALUE`,
`TOKEN_VAZIO`, `UNDEFINED`, `NO_REAL_SOLUTION`,
`MISSING_OBSERVATION`, `NOT_APPLICABLE`, `APPROX_ZERO`.

Every missing gap record has:

`gap_id | token_type | missing_reason | priority | authority |
state | evidence_required | falsifier | next_action | receipt_state |
rollback | claim_allowed`

A `TOKEN_VAZIO` does **not** disappear after finding a plausible
value. The authority must provide a scoped source, actual evidence,
receipt, and falsifier. If a source cannot be retrieved, **preserve
the absent source as typed negative knowledge**.

## 9. Interaction reconstruction: observable closure rule

One logical session is closed as a **reconstruction artifact** only when
all its listed vectors are addressable, every gap is typed, all graph
edges exist with appropriate source-state, falsifier paths and
reversible receipts. **This is not the same as closing the underlying
25 gaps, implementing all 26 functions, or promoting the system.**

Every later version must name this manifest as predecessor,
report a precise delta and retain prior unresolved states. No
project-wide claim is allowed from a single source-side CI check.
