# RAFAELIA — Project Recurrence Manifold V1

**State:** `DRAFT_AUDITABLE / IMPLEMENTED_UNTESTED`  
**claim_allowed:** `false`  
**Extends:** Session Semantic Ledger V1 + Session Semantic Chain V1 + μ Semantic Event V1

## 1. Purpose

Turn the GPT Project surface into a bounded recurrence sensor without concatenating chats or treating project context as durable evidence.

```text
chat/session
→ semantic occurrence
→ recurrence candidate
→ typed relation
→ L9 observation
→ gate
→ TOKEN_VAZIO / evidence
→ μWRITE / receipt
→ longitudinal memory
```

The recurrence layer is a **derived index**, not another corpus copy.

## 2. Invariants

```text
SESSION ≠ LONGITUDINAL_MEMORY ≠ EVIDENCE
SOURCE ≠ ARTEFACT ≠ EXECUTION ≠ EVIDENCE ≠ CLAIM
TOKEN_VAZIO ≠ 0
SEMANTIC_RECURRENCE ≠ CAUSALITY
ALIAS_SIMILARITY ≠ IDENTITY
PROJECT_CONTEXT_COVERAGE ≠ RAW_EXPORT_COVERAGE
```

Public artifacts are alias-only. Raw session IDs, message IDs, private Drive locators, and raw chat content remain outside this public ledger.

## 3. L9 multidimensional receipt

Each recurrence may project onto the useful subset of:

- L — longitudinal evolution;
- O — orthogonal domains;
- T — transversal reuse;
- P — provenance;
- C — contextual meaning;
- R — typed relations;
- I — index/navigation;
- E — evidence/falsifier;
- A — adaptive rerouting.

Unused dimensions remain absent or TOKEN_VAZIO; nine synthetic observations are not fabricated.

## 5. Seed recurrence families

The bounded seed records nine recurring families:

1. number → decomposition → representation → context;
2. source → transform → receipt;
3. TOKEN_VAZIO → evidence → state transition;
4. literal / symbolic / mathematical / computational layer separation;
5. contradiction → classification → supersession;
6. semantic aliases without identity collapse;
7. Ω7 multidirectional analysis;
8. old gap → reappearance → evidence-bound closure;
9. anomaly / paradox / rapport / exploratory vectoring.

These are indexed as project-context observations. They do not claim exhaustive account-wide coverage.

## 6. Gate order

P0:

1. lineage/provenance before re-opening an old gap;
2. execution receipt before promoting implementation state;
3. evidence-specific closure before changing TOKEN_VAZIO;
4. causal gate blocks recurrence-only inference.

P1:

1. exact provider/export occurrence identity;
2. cross-layer bridge/reconstruction tests;
3. canonical sense binding for aliases;
4. formal operator binding for logarithmic/reclusive/correlative/attractor-vectoring lenses.

P2:

- bounded operational definition for rapport and other context-sensitive lenses.

## 7. State transitions

```text
OBSERVED_PROJECT_CONTEXT
→ DERIVED_INDEX
→ VERIFIED_LIMITED
```

Only the indexed relation state moves here. Scientific/physical/causal claims continue through their own evidence gates.

A gap can move:

```text
TOKEN_VAZIO
→ EVIDENCE_BOUND
→ CLOSED_SCOPED
```

only by a successor event/receipt. History is not rewritten.
