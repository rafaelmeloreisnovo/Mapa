### About derivatives, antiderivatives and reversals

The seven line labels are **operator categories**, not automatic calculus. A
label `DERIVATIVE` becomes mathematical only when a function, domain, units and
differentiability conditions are supplied. `ANTIDERIVATIVE` additionally needs
integration constants and boundary conditions. An inverse relation, a narrative
reversal and a causal reversal are distinct claims. The default for causal
interpretation is `TOKEN_VAZIO_CAUSALITY` until temporal order, an intervention
or counterfactual, an explicit causal model and reproducible evidence exist.

## 5. Symbols, ideograms, emoji and “compression”

The factual distinction is:

```text
Unicode code point ≠ rendered glyph ≠ semantic meaning ≠ compression proof
```

Unicode standardizes character codes; a glyph is a rendered shape controlled by
a font and renderer. Color, direction, animation, temperature metaphor and
wave-like reading are not carried by a plain Unicode string unless a separate
format encodes them. They can be useful dimensions of a notation, but only a
versioned frame and decoder make them auditably recoverable.

A possible future frame is:

```text
header(version, alphabet, normalization, units, visual-channel policy)
payload(code points or media bytes)
metadata(direction, layout, color, timing, context)
decoder(versioned inverse or explicit loss boundary)
receipt(input hash, output hash, test vector)
```

Until that frame has deterministic encode/decode and adversarial round-trip
tests, the correct label is `TOKEN_VAZIO_CODEC_SPECIFICATION`, not “lossless
compression.” The system may still call it **organized multichannel notation**
as a `[C]` convention.
