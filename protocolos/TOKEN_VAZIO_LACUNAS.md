# Protocolo de Lacunas

## Principio

A lacuna nao deve ser preenchida com invencao. Ela deve ser marcada, protegida e transformada em proximo teste.

## Modelo

```yaml
id: ""
objeto: ""
estado: "LACUNA"
o_que_existe: ""
o_que_nao_existe: ""
risco_se_inventar: ""
valor_da_lacuna: ""
proxima_medida: ""
status: "protegido"
```

## Uso

Aplicar sempre que faltar arquivo, hash, commit, fonte, data, resultado experimental, log ou evidencia direta.

## Saida esperada

A lacuna deve virar tarefa objetiva, nao conclusao falsa.
