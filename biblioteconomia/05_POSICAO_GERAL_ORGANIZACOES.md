# 05 — Posição Geral das Organizações (Local → Geral)

> Para cada repositório: o **escopo local** que ele declara no próprio README ×
> a **posição geral** que ocupa no acervo. É o movimento pedido — ampliar a
> contextualização de cada organização, do seu recorte para o mapa inteiro.

## Leitura de conjunto

- O acervo tem uma **coluna vertebral técnica** (núcleo → plataforma → cognição) que
  sobe do C/ASM freestanding até a IA de larga escala.
- Tem uma **cúpula epistêmica dupla**: à esquerda, ciência publicada (RLL, matemática);
  à direita, filosofia-espírito (LivroVivo, Blackhole, publicações).
- No meio, a **camada jurídico-ética** (RafPolimata, LGPD, Rafaelia_Private) costura as
  duas cúpulas com governança e direitos.
- No topo, a **camada de organização** (Mapa, MemRafcode) torna tudo rastreável — é onde
  esta biblioteconomia vive.

> Nenhuma organização é ilha: a posição geral existe para que uma decisão sobre um repo
> considere seu papel no todo, não só seu README isolado.
