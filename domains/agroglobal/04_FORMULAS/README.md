# Fórmulas agrícolas e econômicas — índice V1

Autoridade: derivação algébrica sob restrições dimensionais; não comprova dado externo.
Abrir formulas_v1.json e verificar preconditions de cada expressão.
Convertendo futuros: aplicar pesos legais de bushel específicos; manter preço em centavos, mês e base.
Exportação: spot/cash, futuro, PTAX e cambial intradia são classes distintas. Futuros ≠ sacas vendidas.
Consórcios: LER/IEA mede equivalência de área em comparações agronômicas adequadas; não prova lucratividade.
Testes de borda: denominadores zero, unidade divergente, FX trocado, base temporal mismatch, previsão vs observado → rejeitar ou TOKEN_VAZIO.
