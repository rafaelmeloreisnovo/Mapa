## Função

O projeto EXPLORAR amplia o espaço de candidatos visuais e conceituais: com e sem simetria, com e sem foco, com e sem objetos reconhecíveis. O Mapa não declara esses candidatos verdadeiros; ele os encaminha à autoridade adequada.

```text
fonte visual
→ manifesto/hash
→ claim atômico
→ direção analítica
→ autoridade local
→ método/teste
→ evidência
→ decisão
→ rollback ou próxima iteração
```

A invariante é:

```text
símbolo preservado + prova registrada + execução auditável
```

## Dois fluxos que não podem ser confundidos

### Emergência de padrão

```text
OBSERVE → ISOLATE → REPLICATE → MEASURE → MODEL → FALSIFY → PROMOTE_OR_PRESERVE
```

Um padrão belo ou recorrente entra como `EMERGENT_SIGNAL`, nunca como teorema.

### Emergência operacional

```text
DETECT → FREEZE_CLAIMS → PRESERVE_EVIDENCE → CONTAIN → ROLLBACK → RECOVER → POSTMORTEM
```

Durante incidente, nenhum claim é promovido. O rollback só é real quando ensaiado.
